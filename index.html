راه‌اندازی چک‌لیست اشتراکی

یک‌بار Firebase رایگان بسازید تا تغییرات برای همه نمایش داده شود.

  1. برو به console.firebase.google.com
  2. پروژه جدید بساز (مثلاً cafe-checklist)
  3. از منو: Build → Realtime Database → Create Database
  4. حالت را موقتاً Test mode بگذار (قوانین باز برای شروع)
  5. برو به ⚙️ Project settings → Your apps → Web (</>)
  6. یک اپ وب ثبت کن و بخش firebaseConfig را کپی کن
  7. اینجا بچسبان و ذخیره را بزن

databaseURL باید وجود داشته باشد (Realtime Database). بعد از راه‌اندازی، همین لینک را به بقیه بدهید.

یا ادامه با حالت فقط‌محلی (بدون اشتراک)
